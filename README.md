**TaskPulse** is a feature-rich, high-performance, responsive task management web application built with **Vanilla HTML, CSS, and JavaScript**. Designed with a modern dark/light glassmorphic UI, real-time analytics, local storage synchronization, subtasks checklist, search fuzzy-matching, category filtering, and export/import functionality.

## ✨ Features

- 🌓 **Dynamic Dark & Light Mode**: Seamless theme switcher saved to local storage.
- 📊 **Real-time Task Analytics**: Completion progress bar with total, active, completed, and overdue task counters.
- 🏷️ **Priority & Category Tags**: Categorize tasks by Work, Personal, Health, Finance, Shopping, or Education with Low, Medium, and High priority badges.
- 📋 **Subtasks & Checklist**: Create multi-step subtasks inside any task card.
- 🔍 **Instant Search & Multi-Filters**: Filter by task status (All/Active/Done), category, and sort by Due Date, Priority, or Creation Date.
- ⏰ **Due Date & Overdue Tracking**: Visual indicators highlighting upcoming and overdue deadlines.
- 💾 **LocalStorage Persistence & Backup**: Automatic auto-save with JSON export & import options for task backups.
- ⌨️ **Keyboard Shortcuts**: Press `/` to focus the search bar instantly, `Esc` to close modal dialogs.
- 📱 **100% Responsive Design**: Optimized for desktop, tablet, and mobile browsers.

---

## 🛠️ Tech Stack & Architecture

- **HTML5**: Semantic structure, accessible modal dialogs, and SVG icons.
- **CSS3**: Custom CSS variables, Flexbox & CSS Grid, glassmorphism blur effects, keyframe micro-animations.
- **JavaScript (ES6+)**: Object-oriented DOM manipulation, state management, LocalStorage API, and custom toast notification system.

### Step 2: Host Live for FREE on GitHub Pages

1. Go to your GitHub repository on [GitHub.com](https://github.com/gupta-srikakulapu/to-do-list).
2. Click on **Settings** tab (top right of repository menu).
3. On the left sidebar, scroll down and click on **Pages**.
4. Under **Build and deployment** -> **Branch**:
   - Select **`main`** branch.
   - Select **`/ (root)`** folder.
5. Click **Save**.
6. Wait 1 to 2 minutes. GitHub will generate your live link:
   `https://gupta-srikakulapu.github.io/to-do-list/`

2. Click **Add new site** -> **Import an existing project** -> Select **GitHub**.

#### Option B: Vercel
1. Sign up at [Vercel.com](https://vercel.com/).
